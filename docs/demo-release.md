# Ticky — финальная версия для демо

Версия v0.1.0-demo. Дата фиксации 15 ноября 2026.

## Что показываем

Ticky помогает пользователю разобрать уведомление о штрафе, подтвердить сведения и подготовить редактируемое обращение для самостоятельной подачи.

- Выбор штата, загрузка PDF/JPG/PNG или ручной ввод.
- Gemini извлекает поля из загруженного документа. Пользователь исправляет и подтверждает их.
- Для NYC code 38 проверяются сведения ParkNYC, номер машины, время и наличие приложенного чека. Пользователь подтверждает сведения чека и соответствие зоны.
- Другие поддержанные civil/traffic notices проходят общий сбор фактов и подготовку заявления. Подробная правовая база для каждого штата ещё требует расширения.
- Черновик составляется кодом из подтверждённых данных. Проверенные ссылки берутся из локального реестра.
- Редактирование, PDF, возвращение по приватной ссылке, удаление дела.

## Репетиция на 3 минуты

1. Открыть сайт в инкогнито, выбрать New York и подтвердить использование синтетических данных.
2. Загрузить synthetic-ticket.png, запустить распознавание, проверить номер 0000000012, code 38, DEMO123 NY, 11/14/2026 и 1:30 PM.
3. Подтвердить поля и выбрать Through ParkNYC.
4. Загрузить synthetic-parknyc-receipt.png. Указать 11/14/2026, сессию 1:20 PM–2:20 PM, DEMO123, NY, зону 123456. Подтвердить сведения синтетического примера.
5. Открыть отчёт, показать доказательства и официальный источник.
6. Выбрать Use demo access, исправить предложение в черновике, сохранить и скачать PDF.
7. Скопировать приватную ссылку и открыть её в новом сеансе, показать сохранённую правку.

## Что учитывать на защите

Демо предназначено для синтетических документов. Автоматическая подача отсутствует, результат ведомства неизвестен. Универсальная актуальная база законов всех штатов пока не реализована.

Роль Gemini — распознавание документов. Правила, проверки полноты и построение черновика выполняет backend. Чек прикрепляется, а его сведения подтверждает пользователь.

На лендинге представлены гипотезы подписки $20/месяц и $199/год. Billing отключён, демодоступ бесплатный. Эти цены и готовность платить ещё предстоит проверить.

Публичный стенд работает через временный Cloudflare Tunnel с ноутбука. Для показа нужны работающие backend, tunnel и интернет. Ноутбук должен оставаться включённым. При ошибке Gemini можно повторить распознавание или воспользоваться ручным вводом. Для резервного показа заранее сохраните PDF и приватную ссылку на синтетическое дело.

## Разделение выступления

- Участник 1 объясняет pipeline и защиту доступа.
- Участник 2 показывает пользовательский путь и интерфейс.
- Участник 3 объясняет официальные источники, проверки и ограничения.

После фиксации версии меняем только ошибки, мешающие показу. Новые сценарии и функции планируем после хакатона.
